# تشغيل العرض التجريبي لسَليم (محلياً)

بيئة عرض معزولة على جهازك: قاعدة بيانات Supabase محلية، ومساحة «بنك سليم التجريبي» بتسعة أدوار، وتحليل حقيقي عبر Gemini.
لا تلمس الإنتاج ولا بيانات العملاء.

## التشغيل (مرة واحدة لكل جلسة)

```bash
# 1. شغّل Docker Desktop، ثم:
npx supabase start --workdir backend
npm run demo:seed                     # المساحة التجريبية + الأدوار + 4 إعلانات تمويل (آمن عند التكرار)
npx supabase functions serve --workdir backend --env-file backend/supabase/functions/.env
# في نافذة أخرى:
npm run build && npx --workspace frontend vite preview --port 4173
```

افتح `http://localhost:4173/login`، ثم اضغط «دخول تجريبي» واختر دوراً. الأدوار الأساسية ظاهرة مباشرة،
والأدوار المتقدمة (المالك، قائد الامتثال، القانوني، المراجع الخارجي، المشاهد) تحت «الأدوار المتقدمة».
للتبديل بين الأدوار: سجّل الخروج ثم ادخل بدور آخر.

## الإعدادات المطلوبة (محلية فقط، غير متتبَّعة في Git)

| الملف | القيمة | الغرض |
|---|---|---|
| `backend/.env` | `VITE_DEMO_LOGIN=true` | يُظهر بطاقات الدخول التجريبي (معطّل افتراضياً في أي بناء آخر) |
| `backend/supabase/functions/.env` | `DEMO_MODE=true` | يسمح لوسيط الدخول التجريبي بالعمل — **محلياً فقط، أبداً في الإنتاج** |
| `backend/supabase/functions/.env` | `GEMINI_API_KEY`، `GEMINI_MODEL=gemini-3.6-flash`، `GEMINI_FALLBACK_MODEL=gemini-3.1-flash-lite` | التحليل الحقيقي |

الدخول التجريبي محصور في المساحة التجريبية: الوسيط يرفض أي حساب خارجها، ولا يرى أي دور بيانات مساحة أخرى.

## مسار عرض مقترح (10 دقائق)

1. **المسوّق** (`marketer@`): «فحص جديد» ← ارفع `backend/tests/fixtures/synthetic/slimming-tea-ar.webm` ← التقرير:
   تفريغ عربي بتوقيتات، وملاحظات مرتبطة بثوانٍ محددة؛ اضغط ملاحظة لينتقل المقطع إليها.
2. **قائد الامتثال**: «قواعد الشركة» ← أنشئ قاعدة ← «جرّب القاعدة» على إعلان «تمويل سليم — عرض الصيف».
3. **المالك**: اعتمد القاعدة (لا يستطيع كاتبها اعتمادها — فصل المهام) ← سجل التدقيق.
4. **المراجع**: قائمة المراجعة ← قرار على إعلان ← سجل الامتثال والتحقق العام `/verify/<id>`.
5. بدّل اللغة إلى الإنجليزية لعرض الاتجاه LTR.

## لكي تنطبق قواعد البنك (SAMA وقواعد الشركة)

- ارفع من حساب عضو في المساحة (مثل المسوّق). نموذج «فحص جديد» يختار مساحة «بنك سليم التجريبي» افتراضياً؛
  اختيار «شخصي» يعني تحليلاً بالقواعد العامة فقط.
- في حقل **«نوع الاتصال»** اختر **«إعلان عن منتج مالي»**. قواعد SAMA مخصصة لإعلانات المؤسسة المالية نفسها،
  ولا تنطبق على «محتوى برعاية لدى صانع محتوى» (الافتراضي).
- رفع الشريك الخارجي من صفحته الخاصة لا يربط الإعلان بمساحة البنك؛ الشريك يرفع عبر رابط الشريك الخاص بالحملة.

## حدود معروفة

- مفتاح Gemini على **الفئة المجانية: 20 طلباً يومياً لكل نموذج** (يتجدد منتصف الليل بتوقيت المحيط الهادئ،
  نحو 11:00 بتوقيت السعودية). المقطع يستهلك طلبين على الأقل. فعّل الفوترة قبل أي عرض طويل.
- عند ازدحام Google (503) أو تأخر الرد: انتقال فوري إلى `gemini-3.1-flash-lite` ثم إعادة محاولات بفواصل 3 و8 و15 ثانية
  بالتناوب بين النموذجين، ويُسجَّل اسم النموذج الذي أجاب. لا يُستخدم البديل أبداً عند نفاد الحصة (429).
  جودته أقل (ظهرت ملاحظة خاطئة على إعلان بطاقة)، لذا يُفضَّل العرض على `gemini-3.6-flash`.
- عند نفاد الحصة تظهر رسالة «تم الوصول إلى حد استخدام مزوّد التحليل» مع زر «أعد المحاولة»؛ لا نتائج مزيفة.
- التكلفة تظهر «غير معروفة» للنماذج التي ليس لها سعر موثّق (مثل flash-lite)، لا $0.
- قواعد SAMA/CMA في المساحة التجريبية **مسودات** مفعّلة باختيار المساحة، وتظهر كتنبيهات لا كمخالفات ملزمة.
